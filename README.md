# Tic-Tac-Toe

A compact browser game focused on **state transitions, rule evaluation and user interaction**.

## Engineering question

How do we keep a stateful UI predictable when every user action changes the board and can produce a terminal outcome?

## What it demonstrates

- explicit game state
- turn management
- rule evaluation for wins and draws
- derived UI state
- edge cases around invalid or terminal moves

## Run locally

Use the package scripts already defined by the project to start the application, then open the local development URL shown by the tooling.

## Portfolio positioning

This is a deliberately small historical project. It is retained as evidence of hands-on front-end experimentation rather than presented as a current production architecture.

The broader MountainBridge portfolio applies the same principle at larger scale:

**model the problem → define the state → make behaviour observable → test failure cases → explain the trade-offs.**
